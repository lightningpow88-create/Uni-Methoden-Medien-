So geht's

  1. Tippen Sie auf den Stapel. Eine Karte wird aufgedeckt.
  2. Ziehen Sie die Karte an die Linie: weniger Kalorien als das Käsebrötchen nach links, mehr nach rechts.
  3. Liegen alle 15 Karten? Dann starten Sie rechts die Auflösung.

Tipp: Karten an der Linie können Sie verschieben. Antippen vergrößert eine Karte.
